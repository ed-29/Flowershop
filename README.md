# FlowerShop

A modern, responsive website for a flower shop where users can browse bouquets, view product details, and explore contact information.

## Live Demo
https://flowershop-three.vercel.app

## Features
- role based control system for users, shop manager and admin
- Browse bouquet categories
- View product details (image, description, price)
- Add, update and remove items from the catalogue as shop manager
- Responsive layout for desktop & mobile
- Built with React, Vite, CSS modules, Node and mongoDB

## Tech Stack
- React 
- Vite
- Tailwind CSS
- Node
- mongoDB
